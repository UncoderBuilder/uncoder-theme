# Uncoder theme

The free companion theme for the [Uncoder](https://github.com/UncoderBuilder/uncoder) website builder.
A clean, fast canvas that gets out of the way: pages built with Uncoder get the full width, Theme Builder
headers, footers and layouts replace the theme's own, and block-editor posts get readable typography that
follows your Uncoder Design System. It also works without the plugin.

- About 64 KB, no external fonts, no tracking
- Uses your Design System colors and fonts when Uncoder is active

**Website:** [uncoderbuilder.com](https://uncoderbuilder.com) · **Documentation:** [docs.uncoderbuilder.com](https://docs.uncoderbuilder.com)

## Install

1. Download [**uncoder-theme.zip**](https://github.com/UncoderBuilder/uncoder-theme/releases/latest/download/uncoder-theme.zip) from the latest release.
2. In WordPress, go to **Appearance → Themes → Add New → Upload Theme**, choose the zip, install and activate it.

Requires WordPress 6.6 or newer and PHP 8.0 or newer.
